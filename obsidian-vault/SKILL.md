# Obsidian Vault

## Locate the live owner

- Use a vault path supplied by the user first.
- Otherwise resolve workspace links or the nearest vault repository. Never assume a fixed operating-system path.
- Read every applicable `AGENTS.md` and the vault's own router or playbook before acting. Live vault instructions override this skill.

## Work in the vault's language

- Use the vault's preferred search and retrieval tools. If it provides QMD, use QMD before exact-text fallback search.
- Preserve the distinction between captured evidence, synthesis, current project state, and governing instructions.
- Use the link syntax required by the owning surface. A backlink is a provenance relation; an Obsidian backlink graph is one possible rendering, not the definition.
- Do not infer write authority from a request to read, discuss, compare, place, or synthesize. Follow the vault's own approval and completion gates.

## Keep this skill thin

Do not copy a vault's workflow into this skill. Route into the live vault control plane so its current raw-processing, wiki, indexing, and verification rules remain authoritative.
