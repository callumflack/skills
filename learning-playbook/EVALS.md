# Behavioral evaluation

## 2026-09-02

The skill was evaluated in isolated, project-shaped fixtures against an unguided baseline. Candidate labels were removed before an independent judge saw the answers.

### Scenario 1: repeated deterministic failure

The fixture contained two services that had independently skipped credential rotation plus one unrelated typo. The request asked what should become reusable knowledge.

Both guided and unguided answers:

- kept the fixes and adoption oracle in each repository;
- preferred deterministic checks over shared prose;
- retained the KB as synthesis rather than authority;
- discarded the isolated typo; and
- declined to create shared policy or a skill.

The blinded judge passed both answers on all six criteria and found no material benefit from the skill. This scenario establishes parity on an easy boundary; it is not promotion evidence by itself.

### Scenario 2: apparent cross-domain visual method

The fixture contained current Mobile and Web evidence inside one authority domain, a dated Personal screenshot note without a stable oracle, and KB synthesis that explicitly left the cross-domain boundary unresolved. The request asked for guidance that would govern every project.

Both answers correctly kept the current method domain-local, proposed only a cross-domain candidate, separated repository mechanics from the portable claim, and required current Personal adoption evidence.

Only the guided answer additionally required:

- a baseline-versus-candidate behavioral replay;
- both a fitting visual task and a non-applicable counterexample;
- inspection of the acceptance artifact rather than wording recall; and
- root-owner acceptance through an observable adoption oracle.

The blinded judge rated the unguided answer partial on the next-oracle criterion and failed it on behavioral testing. The guided answer passed every criterion. The judge found the difference material because the guided answer tested whether the proposed instruction changed bounded, observable behavior rather than merely collecting another supporting example.

### Limits

These synthetic replays validate the review skill's decision boundary. They do not verify any candidate playbook or provide real cross-project adoption evidence. Each promoted lesson still needs its own source evidence, independent project case, behavioral comparison when agent-facing, and destination oracle.
